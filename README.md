# 📖 Overview

**Games E-commerce Store** is a full-stack web application developed as part of a **Database Systems Lab** project.

The application provides an online platform for browsing, searching, and purchasing digital games while offering a secure and user-friendly shopping experience. It demonstrates practical implementation of modern web technologies, RESTful APIs, authentication, and relational database management.

The frontend is built using **React.js**, **Vite**, and **Tailwind CSS**, while the backend is powered by **Node.js**, **Express.js**, and **Microsoft SQL Server**. This technology stack is consistent with the project documentation. :contentReference[oaicite:0]{index=0}

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/USERNAME/games-ecommerce-store.git
```

### Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

### Configure Database

Update your SQL Server configuration in the backend before running the project.

### Run Backend

```bash
npm run dev
```

### Run Frontend

```bash
npm run dev
```
